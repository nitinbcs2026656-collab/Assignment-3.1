# Assignment 3.1 — Two-Page Website

**index.html**
```html
<!DOCTYPE html>
<html>
<head><title>My Website</title></head>
<body>
    <h1>My Website</h1>
    <a href="index.html">Home</a> |
    <a href="about.html">About</a>
    <p>Welcome to my website!</p>
    <a href="https://google.com" target="_blank"
       rel="noopener noreferrer">Google</a>
</body>
</html>
```

**about.html**
```html
<!DOCTYPE html>
<html>
<head><title>About</title></head>
<body>
    <h1>About Me</h1>
    <a href="index.html">Home</a> |
    <a href="about.html">About</a>
    <p>I am learning HTML web development.</p>
</body>
</html>
```

**Submission:** Save both files in the same folder, run `index.html` using Live Server, test the links, and submit a screenshot.
